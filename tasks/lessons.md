# Lessons

- **Confirmar antes de push a `main`.** `main` despliega automáticamente (Railway, y también un proyecto de Vercel conectado al repo). Los cambios van en una rama `feature/*` salvo que el usuario pida explícitamente subir a `main`.
- **No asumir a qué se refiere "el parche".** Cuando el usuario mencione un cambio anterior de forma vaga, identificar el commit exacto (hash + descripción) y confirmarlo antes de reescribir o revertir nada.
